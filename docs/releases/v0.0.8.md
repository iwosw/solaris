# Solaris v0.0.8

Preliminary release for Minecraft Java Edition **26.1.2**. Maturity remains
**draft**. This release replaces the server core: `solaris` is now the core v2
server (native tick with deterministic intent merge, native storage plus tick
write-ahead log). The v1 server and its crates are removed.

## Changelog since v0.0.7

### New core and storage

- Single native tick owns gameplay. Snapshot reads run in parallel and
  produce owned intents. A deterministic serial merge applies them.
  Connections and presentation live in the edge.
- The world persists only to a native store plus a tick write-ahead log.
  Recovery replays the latest checkpoint and the contiguous WAL after it.
  Corrupt or unsupported stored state refuses to start.
- Offline `world import-anvil` / `world export-anvil` convert vanilla worlds.
  Unknown tags and saved data are kept verbatim. Old worlds from DataVersion
  2860 through 4790 are upgraded on import.
- Statistics, advancements (vanilla definitions including recipe unlocks),
  scoreboards and teams.

### Gameplay

- Nether, End, portals and the ender dragon fight; vanilla 26.1 world layout.
- Special mobs, mounts and vehicles.
- Sculk, vibrations and the warden. Trial spawners, vaults, omens and wind
  charges.
- Mace and the new effects, crafter, shelves, Golden Dandelion.
- Copper chests, copper golems and statues. Bees, allays, jukeboxes.
- Raids and Hero of the Village; conduits and dolphins.
- Piglin bartering, armor stands, wandering traders, fishing loot tables.
- Slime and magma cube sizes; enderman, creaking, giant and illusioner
  behaviour.
- Iron golems and snow golems built by players. Player-built iron golems
  never target players.
- Elytra gliding with firework boosts.
- Beacons: pyramid levels, payment menu and area effects.

### Plugins

- Wasmtime plugin packages (`solaris:plugin@0.7.0`) load from
  `[plugins].directory`. Plugin storage, receipts and custody commit in the
  same tick WAL batch as the world.

### Performance

- 100 clients against about 100,000 mixed mobs now run at about 16 TPS on the
  reference host (frame-pointer build). Earlier runs were below 10 TPS.
- Entity data is laid out more compactly. Hot passes no longer scan every
  entity row.

## Upgrade notes

Back up the world and configuration before upgrading. The new server does not
open v0.0.7 world directories in place. Convert a vanilla-format (Anvil) world
once with `solaris --config server.toml world import-anvil --source <anvil-world>
--destination <native-world> --receipt import.json`. Existing configuration
files are not rewritten.

## Validation boundary and known gaps

- Validation for this release is recorded in the release receipt. Gates that
  did not run are listed there as not run.
- Not simulated yet: command blocks, `/function` and `/schedule`, custom boss
  bars, stopwatches, and creaking hearts. Commands such as `/data`, `/loot`,
  `/clone`, `/forceload` and `/datapack` are absent.
- Native-100 throughput is below 20 TPS. Larger cohorts (500 or 1000 clients
  with 100,000 mobs) are capacity-limited.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/kaiserproger/solaris/v0.0.8/install.sh | \
  SOLARIS_VERSION="v0.0.8" bash
```

Linux x86_64 and AArch64 archives contain the server, starter configuration,
README, changelog, version marker, and licenses. Pin `v0.0.8`: GitHub's
`latest` alias does not select a prerelease.

Before the first start, import the vanilla content once. This downloads the
Mojang server for 26.1.2, checks its size and SHA-1, and derives a local
content cache. Solaris does not redistribute Mojang data:

```sh
solaris content import --version 26.1.2 --download
```

The server refuses to start without that cache and names the command to run.
